3.4.3 同策略与异策略的区别

1. 概述

在强化学习中，同策略（On-Policy）和异策略（Off-Policy）是两种不同的学习策略。它们的主要区别在于生成样本的策略与更新价值函数时所使用的策略是否相同。同策略算法使用同一个策略进行行为选择和策略更新，而异策略算法使用不同的策略进行行为选择和策略更新。

2. 同策略

定义： 同策略算法在学习过程中，使用同一个策略进行行为选择和策略更新。即，行为策略（Behavior Policy）和目标策略（Target Policy）是相同的。

示例：Sarsa 算法

  • 更新公式： $$ Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)] $$ 其中，$Q(s_{t+1}, a_{t+1})$ 是在策略 $\pi$ 下选择的动作 $a_{t+1}$ 的 Q 值。
  • 特点：
    • 探索与利用：由于行为策略和目标策略相同，同策略算法在探索和利用之间具有一致性。
    • 保守性：同策略算法通常较为保守，尤其在面对高风险环境时，会选择更安全的路径。
    • 逐步更新：每一步都使用实际执行的动作进行更新，保证了策略的一致性和稳定性。

3. 异策略

定义： 异策略算法在学习过程中，使用不同的策略进行行为选择和策略更新。即，行为策略和目标策略是不同的。

示例：Q 学习算法

  • 更新公式： $$ Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)] $$ 其中，$\max_{a'} Q(s_{t+1}, a')$ 是在下一个状态 $s_{t+1}$ 中选择最优动作 $a'$ 的 Q 值。
  • 特点：
    • 探索与利用分离：行为策略用于探索，目标策略用于利用最大化回报。
    • 激进性：异策略算法更加激进，因为它可以大胆地利用行为策略进行探索，而目标策略直接优化最优动作。
    • 快速收敛：通过选择最大 Q 值，异策略算法可以更快地找到最优策略，但在高噪声环境中可能不稳定。

4. 同策略与异策略的比较

  1. 策略使用：

    • 同策略：行为策略和目标策略相同，策略一致性强。
    • 异策略：行为策略和目标策略不同，探索与利用分离。

  2. 更新公式：

    • 同策略：基于实际执行的动作 $a_{t+1}$ 更新 Q 值。
    • 异策略：基于最大化未来回报的动作 $a'$ 更新 Q 值。

  3. 探索与利用：

    • 同策略：在策略评估和改进时需要兼顾探索与利用，可能导致策略较为保守。
    • 异策略：分离探索与利用，可以更大胆地进行探索，目标策略直接最大化回报。

  4. 应用场景：

    • 同策略：适用于需要稳定性和安全性的环境，如导航和路径规划。
    • 异策略：适用于需要快速收敛和高效探索的环境，如游戏和金融交易。

总结

同策略和异策略是强化学习中的两种重要方法，它们在策略使用、更新公式和探索与利用等方面存在显著差异。理解同策略与异策略的区别，有助于选择合适的算法来解决具体的强化学习问题。
